Kroo Desktop gives your team a native Windows experience for accessing construction project data, with automatic updates built in.

## Prerequisites

- **Windows 10 or later** (64-bit)
- An active Kroo account — contact [implementations@getkroo.com](mailto:implementations@getkroo.com) if you need access

## Download

Download the latest Kroo Windows installer:

<Card title="Download Kroo for Windows" icon="download" href="https://downloads.getkroo.com/desktop/kroo.Setup.latest.exe">
  Windows installer (.exe)
</Card>

<Info>
This link always downloads the latest Kroo Desktop release. If you already use Kroo Desktop v1.0.0, install once manually; later updates download automatically.
</Info>

## Installation

<Steps>
<Step title="Run the installer">
  Double-click the downloaded `kroo.Setup.latest.exe` file to begin installation.
</Step>

<Step title="Sign in">
  The app will launch automatically after installation. Sign in with your Kroo credentials.
</Step>

<Step title="Verify the app is working">
  After signing in, confirm you can see your project data.
</Step>
</Steps>

## Auto-Updates

The app checks for updates automatically when it opens. Updates download in the background and prompt you to restart. If you choose **Later**, the update installs when you close the app.
