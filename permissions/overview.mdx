Kroo's permissions system gives organizations precise control over who can access each feature, tool, and dataset. It is designed to make data access easier to manage without sacrificing governance. When set up correctly, users can work confidently in the Kroo tools and data they are authorized to use, and only within the right scope of access. These features can include:

- Kroo Studio Dashboards
- Data Viewer
- Data Dictionary
- Kris
- MCPs

Permissions are primarily managed through two methods:

1. **[Roles](/permissions/roles)**
2. **[Resources](/permissions/resources)**

<Info>
**Note**: Row Level Permissions govern underlying data access. See **[Row Level Permissions (within Database Access)](/permissions/row-level-permissions)** for more detail.
</Info>

**Roles** are managed centrally in Settings. They control access to Kroo features and determine who can view or configure Connections, which are your organization's connected data sources. **Resources** control access to dynamic, customer-specific areas of the Kroo platform. Resource permissions are managed within the tool or dataset they apply to. A user's effective access combines their Role and Resource permissions.
