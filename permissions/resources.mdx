<Info>
This permissions model takes effect on **October 18, 2026**. Before then, Kroo has only two user types: **Admins** and **Non-Admins**.
</Info>

Resources are a collection of Kroo platform tools that are unique to each customer. Resultantly, these permissions are handled slightly differently than Features and Connections as they require further granularity. Resources include:

- Dashboards
  - Studio Dashboards
  - Embedded Power BI Dashboards
- Kroo Projects
- Database Access
  - [Row Level Permissions](/permissions/row-level-permissions)

<Info>
Resource permissions must be given to users/groups so that they have access to Kroo data. This is essential for them to be able to interact with Kroo's tools and features. To enable this access Row-level Permissions must be configured and granted to groups and users.
</Info>

Each of these areas of the platform can be assigned by group or by user within the Resource Access Pane that opens from the right:

Resource levels are View, Create and Admin. View opens a granted item, Create makes new ones, and Admin grants access to every item of that type. Broken out these options are:

- 0 - Cannot View
- 1 - Can View
- 2 - Can Edit
- 3 - Can Manage Access

<Info>
Within a resource, a single user's access could be applied at the user level as well as at any number of roles that user has been assigned to which may also have an assignment to that resource. In the event of a conflict between these assignments, a user's resulting access will be defined by the highest level from those assignments for a given feature or connection.
</Info>
